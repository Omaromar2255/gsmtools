# 11) ملاحظات
# ============================================================
[NOTE]	Port 2600 = مصعد الصلاحيات (UID 1000) — يتطلب فتحه قبل كل عملية
[NOTE]	audiocoredebug يعمل بصلاحية system (UID 1000) وليس root (UID 0)
[NOTE]	SLB.bin = SIM Lock Byte في /efs/root/data/ — فك القفل بصفر مباشر
[NOTE]	PreconfigActivity في CID Manager يغيّر CSC بدون أوامر AT
[NOTE]	knox.kg.state يحدد ما إذا كان Knox Guard مقفلاً (RECHECK/LOCKED/UNLOCKED)
[NOTE]	input keyevent 219 = KEYCODE_ASSIST — يفتح المساعد المحدد في settings
[NOTE]	uiautomator dump يلتقط XML للواجهة → استخراج إحداثيات أزرار
[NOTE]	AT يبني: echo '<payload>' | toybox nc 127.0.0.1 2600 — عبر popen
