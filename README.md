# GSM Tools — المنظومة المتكاملة لأدوات فحص وبرمجة المودم وفك القفل

> **مستودع الأوامر والمراجع الشاملة لنظام GSM Tools (Samsung, Qualcomm, Shannon & Android Services)**  
> **الإصدار المرجعي:** 3.0 (تاريخ التحديث: أكتوبر 2026)

---

## 📖 نظرة عامة (Overview)

هذا المستودع هو المرجع الشامل لجميع الأوامر المكتشفة والمفكوكة والمدعومة في أجهزة الهواتف الذكية (وخاصة سامسونج بإصدارات معالجات Exynos/Shannon و Qualcomm Snapdragon).
تم استخراج هذه الأوامر عبر الهندسة العكسية لملفات `AT` الثنائية، تفريغ الذاكرة الحية (Live RAM) أثناء تشغيل الأداة على هواتف متصلة، وتحليل مكتبات الراديو `libril.so` و `libsecril-client.so`، ومطابقتها وتوثيقها بشكل كامل مع المعايير الدولية والبحث الميداني.

تمت إعادة ترتيب وتنظيم جميع الملفات المكتشفة في مجلدات متخصصة ومصنفة لتسهيل الوصول إليها عند بناء النظام:

│   ├── MCC_MNC_COMMANDS.md              # دليل أوامر قراءة وتعديل MCC/MNC وحزم SRELOCK
│   └── REVERSE_ENGINEERING_STORY.md     # القصة الهندسية لفك تشفير ملف AT واستخراج الرموز

│   ├── LIBRIL_COMMANDS.txt              # أوامر ومسارات مكتبات RIL
│   ├── OBSERVED_AT_COMMANDS.txt         # أوامر AT المرصودة في جلسات العمل
│   ├── XOR_DECODED_STRINGS.txt          # النصوص المفكوكة بمفاتيح XOR من الرام
│   ├── AT_ALL_STRINGS.json              # مصفوفة JSON لجميع نصوص الأداة
│   └── AT_XREF_HITS.json               # تقاطعات الاستدعاءات (Cross-References)

│
├── source_dumps/                        # مخرجات الهندسة العكسية والملفات الثنائية
│   ├── ghidra/                          # كود C المفكوك من Ghidra وقوائم الدوال
│   │   ├── GHIDRA_DECOMPILED.c          # الكود الكامل بعد فك التعمية
│   │   ├── KEY_FUNCTIONS.c              # دوال منطق الاتصال بالمودم والشل

│   │   └── classes_v2.dex               # ملف بايت كود أندرويد المسترجع

## ⚡ أبرز الأوامر الموثقة في المنظومة (Key Supported Commands)

| الأمر | الوظيفة التقنية | طريقة الاستخدام |
|---|---|---|
| `AT+DEVCONINFO` | قراءة تفصيلية شاملة لهوية الجهاز، المعالج، الشبكة، التشفير والموديل | استعلام فوري لمعلومات الهاتف |
| `AT+PRECONFG=1,0` | قراءة كود المبيعات والمنطقة الحالي (CSC) | فحص توجيه الهاتف |
| `AT+PRECONFG=2,<CSC>` | كتابة وتغيير كود المنطقة (CSC) بدون روت | تغيير المشغل (مثل `XAA`, `VZW`) |
| `AT+SWATD=0 / AT+ACTIVATE` | فتح قنوات المعالجة التحتية للمودم وتهيئة منفذ المصنع | تسلسل تفعيل وضع التعديل |
| `AT+AKSEEDNO=1,0` | طلب بذرة التحدي الأمني (Security Challenge Seed) | فك حماية شهادات المودم و SPR |
| `AT+CPIN?` | التحقق من حالة جاهزية شريحة SIM | فحص وجود الشريحة وأقفال PIN/PUK |
| `AT+CLCK="PN",2` | استعلام حالة قفل الشبكة الأساسي (Network Lock) | `0` تعني مفتوح، `1` تعني مقفول |
| `AT+VERSNAME=1,9,0` | قراءة إصدار النظام والبرمجيات الدقيق من المودم | التحقق من الحماية ومستوى التصحيح |
| `AT+SERIALNO=1,0` | قراءة الرقم التسلسلي للعتاد مباشرة من NVRAM | استرجاع السيريال الأصلي |
| `AT+IMEITEST=1,0` | قراءة رقم IMEI العتادي المخزن بالمودم | التأكد من سلامة المعرف الدولي |
| `AT+CFUN=1,1` | إعادة تشغيل معالج المودم والراديو فورياً | تطبيق التغييرات وإعادة المزامنة |
| `AT+FACTORST=0,0` | إعادة ضبط المصنع الكامل للمودم ومسح الكاش | تصفير إعدادات الشبكة المعلقة |
| `SETSPR / GETSPR` | أوامر داخلية لقراءة وكتابة بروفايل المشغل وقفل SPR | قفل/فك قفل المشغل التلقائي |
| `SRELOCK1` | أمر إعادة قفل الهاتف على شبكة محددة بقائمة MCC/MNC | إعادة القفل المخصص |

> للاطلاع على الشرح الكامل لجميع المعاملات والردود والأخطاء، راجع:  
> [الموسوعة الشاملة للأوامر](docs/COMMANDS_ENCYCLOPEDIA.md).

## 🚀 كيفية استخدام الأدوات المساعدة (Using the Tools)

### 1) أداة فحص واختبار أوامر AT (`tools/at_tester.py`)

يمكن تشغيل الأداة عبر بايثون 3.12 (المثبت على الجهاز) لفحص المنافذ أو إرسال الأوامر:

```bash
# 1. عرض منافذ المودم المتوفرة على الكمبيوتر:
python tools/at_tester.py --list

# 2. تشغيل الفحص الشامل التلقائي عبر منفذ المودم (مثال COM3):
python tools/at_tester.py -p COM3 --diag

# 3. إرسال أمر AT فردي:
python tools/at_tester.py -p COM3 -c "AT+DEVCONINFO"

# 4. تغيير CSC مباشرة مع تسلسل التهيئة:
python tools/at_tester.py -p COM3 --csc XAA

# 5. الدخول في وضع موجه الأوامر التفاعلي المباشر:
python tools/at_tester.py -p COM3

# 6. استخدام وضع ADB المباشر (عند عدم توفر منفذ تسلسلي خارجي):
python tools/at_tester.py --adb -c "AT+DEVCONINFO"
```

### 2) مولد مفاتيح التحقق الأمني (`tools/auth_keygen.py`)

عند تشغيل الأداة على الهاتف وطلب رمز التحقق `Enter AuthKey:` استجابة للتوكن `Token AuthKey:`:

```bash
python tools/auth_keygen.py <TOKEN_HEX_64>
```

## 🛠️ متطلبات البناء على الجهاز الآخر (Build Requirements)

نظراً لأن تجميع النظام الكامل يحتاج إلى موارد وتجهيزات برمجية، يمكنك نقل المستودع إلى الجهاز المستهدف وبنائه كالتالي:

1. **لتجميع تطبيق سطح المكتب (GsmTools.Desktop):**
   - تثبيت [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).
   - تشغيل أمر البناء:
     ```bash
     dotnet build GsmTools.Desktop/GsmTools.Desktop.csproj -c Release
     ```
2. **لتجميع جسر المودم (at-bridge للهاتف):**
   - تثبيت [Android NDK r25b+](https://developer.android.com/ndk/downloads).
   - تشغيل سكربت التجميع:
     ```bash
     cd at-bridge
     build.bat
     ```
